# Fenneks Lern-Oase

Tägliche Lern-Mission mit Mathe, Englisch-Vokabeln und Deutsch-Rechtschreibung für die 5. Klasse. Mit jeder Mission wächst eine Oase.

- Neue Vokabeln und Aufgaben stehen in `inhalte.js`.
- Läuft im Browser und lässt sich in Chrome über „App installieren“ auf den Startbildschirm legen.
- Der Lernfortschritt wird nur auf dem jeweiligen Gerät gespeichert.
